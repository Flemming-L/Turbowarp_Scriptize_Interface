# Turbowarp_Scriptize_Interface Turbowarp代码脚本化接口
一份测试品，可以引入Turbowarp文件中，从而在外部编写脚本并加载内容，功能由原生TW及以下扩展实现:  
XML by [mybearworld](https://scratch.mit.edu/users/mybearworld/)  
文件 by turbowarp  
文本 by [CST1229](https://scratch.mit.edu/users/CST1229/) ,[BludIsAnLemon](https://scratch.mit.edu/users/BludIsAnLemon/) 和[man-o-valor](https://scratch.mit.edu/users/man-o-valor/)  
Lily的工具箱 by [LilyMakesThings](https://scratch.mit.edu/users/LilyMakesThings/)  
变量与列表 by [qxsck](https://scratch.mit.edu/users/qxsck/)  
临时变量 by [LilyMakesThings](https://scratch.mit.edu/users/LilyMakesThings/)和[Mio](https://scratch.mit.edu/users/0znzw/)  
JSON by [Skyhigh173](https://scratch.mit.edu/users/Skyhigh173/)和[Mio](https://scratch.mit.edu/users/0znzw/)  
Script Control by [SharkPool-SP](https://github.com/SharkPool-SP/)  
本地文件管理 by [DustDot](https://space.bilibili.com/302475547)  
Messages+ by [SharkPool-SP](https://github.com/SharkPool-SP/)

## 如何使用
- 直接使用
1. 下载整包（打包的Electron 桌面应用）并运行，第一次运行时应该会在exe所在目录下生成**script**文件夹；  
  
2. 在文件夹中添加脚本，命名为**角色名.txt**；角色会默认读取对应的脚本。脚本的书写格式见**使用说明.txt**  
  
3. 检查代码，再次打开程序，此时你的代码应该会被正确运行了。  

- 作为接口使用
1.下载.sb3工程文件并打开。此时**本地文件管理**插件应该会弹窗提示安装补丁，如果你的TurboWarp来自Microsoft Store，这一步将无法完成，请安装官网版本，并将安装目录设置在你找得到的位置。  

2.照常使用，制作你的游戏或者别的什么，但是不要动接口相关的代码。如果你的作品包含多个角色，让每个角色都复制一份接口的代码。  
  
3.自行打包，并为想要使用接口的人提供相关说明文档（如你使用的内部变量，每个角色的名称，自制积木等）

## 注意事项
- 检查代码……我无法保证在测试版中代码的运行会出现什么bug。如果你确认代码无误却出现了bug，请向[我的Bilibili账号](https://space.bilibili.com/3493293801343055) 投递。
- 作为一个“编辑器套编辑器”的产品，我只能说：不要对它的性能有太高期待，不要想着用它从零写出什么东西，它的主要作用还是作接口。
